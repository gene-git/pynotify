  • mask : the mask for this event.

  • event_types : the list of individual event masks which are or’ed together to make the mask.

  • path : the path to be/being watched..

class pynotify.InotifyMask(*values)

Bases: IntFlag

Mask values from /usr/include/sys/inotify.h. Please see the header file for description of events.

Masks can be bitwise OR together. For example IN_CLOSE can be written as (IN_CLOSE_WRITE | IN_CLOSE_NOWRITE).
